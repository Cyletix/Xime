# CyIME 1.0.3

正式版，可覆盖安装 1.0.0–1.0.3 测试包，无需卸载或清除应用数据。

## 词库升级

- 内置中文和日语词库、方案及脚本按内容版本自动更新，解决旧文件存在就跳过更新的问题。
- 替换前备份同名旧文件；词库发生更新后重建编译缓存。
- 保留用户词频、个人词库、自定义短语和 `.custom.yaml` 补丁。
- 首次升级需要重新部署词库；日常启动不重复读取大词库做完整校验。

## 输入与布局修复

- 保护未完成输入、部分选词和联想等待期间的正文，修复退格和删除上滑误作用于正文的问题。
- 日语未完成罗马音保留实际字母，支持词语补全；修正 `yoy` 出现错误促音候选的问题。
- 九键保留单数字对应声母的召回，改进短语候选与词频学习。
- 候选展开按键盘实际宽度分页，修复平板悬浮窗口中的异常排布。
- 固定与悬浮键盘均可通过边框调整尺寸、拖动移动；固定键盘支持左右位置保存。
- 分离语言选择与当前语言内部的输入模式，改善平板模式选择面板布局。
- 编辑方向盘光效按扇形裁切，保留方形光斑并调整完整淡出时间。

## 模型与来源

- 模型目录随应用提供，直接连接发布者下载地址并校验文件，不再依赖上游模型市场索引。
- 修复模型下载进度、安装完成状态和离开页面中断下载的问题。
- 帮助入口改为 CyIME 文档。可选插件和第三方方案市场本轮仍保留兼容。
- 保留 Xime 及依赖的版权、来源和 GPLv3 许可说明。

## 安装包

一般手机、平板选择 `arm64-v8a`；不确定架构时选择 `universal`。其余架构包供对应设备使用。
发布附带 SHA-256 校验文件。签名与已发布的 1.0.0 一致，支持保留数据覆盖升级。
