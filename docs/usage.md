# CyIME 使用说明

## 词库与升级

首次启用自动安装 APK 内附的中文和日语词库，无需先去市场下载。
升级后按内置内容版本校验词库、方案和相关脚本；更新发生时清除旧编译缓存并重新部署。
同名内置文件默认采用新版，替换前保存在应用私有目录 `rime-upgrade-backups`。
用户词频数据库、个人词库、自定义短语及 `.custom.yaml` 补丁保留。
建议用个人词库或补丁定制，避免直接修改内置同名文件。首次部署期间请等待初始化完成。

## 模型下载

语音、手写、智能联想的模型清单随应用提供，直接连接原发布地址并校验 SHA-256；不再先查询 Xime 模型市场。
可选的第三方输入方案和插件市场本轮仍保留兼容，尚未完全迁移。
模型属于各自作者，具体许可见模型详情。低性能设备可关闭智能联想，保留词库候选。

## 布局调整

调节状态下拖动边框改变尺寸，拖动移动区域改变位置。固定键盘也支持调整宽度和左右位置。
确认后保存；取消恢复进入调节前的布局。语言键单击切换英文，长按选择语言；工具栏输入模式只显示当前语言的方案。
